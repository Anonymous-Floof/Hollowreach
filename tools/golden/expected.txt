chunk(*, v7, *)  # NEW gen version: three flower species join the meadow roll.
                 # Note what is NOT declared here: not one v1-v6 chunk label. The
                 # roll draws the same hashes in the same order and only the species
                 # count it scales them by changed, and the new blocks were appended
                 # rather than inserted — so every older world generates bit for bit
                 # what it always did. That zero is the check; if a v6 label ever
                 # appears in this file, gen v7 has leaked out of its gate.

# Repainted NEUTRAL so a dye multiplies onto them at full strength. The bed's
# blanket was red and its frame brown, so a blue dye over it came out near-black;
# the glass had a cyan cast that shifted every colour mixed through it. The tests
# assert the result (testDyeing walks every dyeable block's tiles and demands
# near-greyscale) — these declarations only say the change was on purpose.

tile(block/bed_head_top)
tile(block/bed_foot_top)
tile(block/bed_side)
tile(block/bed_bottom)   # NEW: its own tile, because the bed used to share the
                         # actual planks texture and neutralising THAT would have
                         # turned every wooden floor in the game grey.
