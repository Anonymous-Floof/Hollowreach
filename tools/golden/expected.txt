# --- 2.5.0: the gate was re-anchored, and the dump grew to fit ---------------
#
# Every entry here is an ADDITION. The baseline in this directory was generated
# by the shipped 2.4.0 binary, and all 217 gen labels, all 158 atlas tiles, all
# 209 recipes and all 30 meshes it emits are reproduced by this build without a
# single value moving. Nothing below is a changed number; they are labels 2.4.0
# had no way to emit.
#
# Worlds generate at kGenVersion, which is 4. The dump stopped at 2 because
# versions 3 and 4 do not exist in the JavaScript that used to be the reference,
# so the check standing between a release and terrain shifting under every
# existing save could not cover the version anyone actually plays.
heightAt(*, v3)          # gen versions past the two the JS had
heightAt(*, v4)
surfacePreview(*, v3)
surfacePreview(*, v4)
chunk(*, v3, *)
chunk(*, v4, *)

# The `chunk` hashes cover the bottom 128 layers, which was the whole of the

# self-anchored baseline could be checked against the last JS-anchored release;
# chunkFull covers all 192, and is what actually guards the underground added
# at gen v3. See the note on kJsCells in src/dev/golden.cpp.
chunkFull(*)             # the 64 layers the old hashes could never see
